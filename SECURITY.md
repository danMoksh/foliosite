# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest version on the default branch.

| Version | Supported          |
| :------ | :----------------- |
| Latest  | Yes |
| < 1.0   | No                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow responsible disclosure guidelines:

1. **Do not create public GitHub issues or discussions** for sensitive vulnerabilities.
2. Report the vulnerability privately via **[GitHub Private Vulnerability Reporting](https://github.com/danMoksh/foliosite/security/advisories/new)** or email directly to **mokshdandotiya@gmail.com**.
3. Please include:
   - A detailed description of the issue
   - Step-by-step reproduction steps or a minimal proof of concept (PoC)
   - Potential impact of the vulnerability

## Response SLA

- **Initial Acknowledgement**: Within 48 hours
- **Triage & Assessment**: Within 5 business days
- **Fix / Remediation**: We prioritize critical issues and aim to deploy patches promptly.

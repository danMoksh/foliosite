## Overview

This repository hosts the source code for [Moksh Dandotiya's portfolio](https://github.com/danMoksh). Built with high-performance animations, procedural Three.js wireframes, custom retro PCB aesthetics, and interactive project deep-dives covering autonomous drones, edge AI vision systems, hardware hacks, and systems engineering.

### Key Highlights
- **Interactive 3D CAD/Drone Models**: Physics-informed procedural wireframe rendering using Three.js and GLTF assets.
- **Retro PCB Aesthetics**: Custom procedural PCB circuit headers, tactile micro-interactions, and retro terminal styling.
- **Deep Technical Case Studies**: In-depth architecture write-ups for autonomous VTOL UAVs, runway debris detection, and embedded devices.

## ️ Installation

### Prerequisites
- **Node.js**: Version 18.0.0 or higher
- **Package Manager**: `npm`, `yarn`, `pnpm`, or `bun`

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/danMoksh/foliosite.git
   cd foliosite
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

---

## Usage

### Development Server
Run the local Vite development server with Hot Module Replacement (HMR):
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### Production Build
Compile and bundle production-ready assets into the `dist/` folder:
```bash
npm run build
```

### Preview Build
Locally preview the generated production build:
```bash
npm run preview
```
